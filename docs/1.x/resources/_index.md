# Resources

`McpResource` wraps a filament resource and decides how it's exposed: which operations an agent gets, what it may read, and what it may write.

Almost none of that is redeclared. The tools are generated from your existing form schema, so the following pages are mostly about the places where the wire format and your panel differ, and about narrowing what the generated tools reach.
